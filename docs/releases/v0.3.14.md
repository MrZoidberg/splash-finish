# Splash Finish 0.3.14

- A refreshed inbox window from the shared bobuk.io component library, BobukKit:
  a rounded frame with an amber accent line, matching Ting and Lowkey.
- Shortcut hints at the bottom of the inbox now show each key next to its action.
  Each hint stays together and moves to a new line when space is limited.
- Notification cards, links, pi questions, keyboard commands, light and dark
  themes, and Increased Contrast work as before.

Your inbox, settings and agent integrations are retained. Homebrew copies update with
**Update Splash Finish via Homebrew…**; standalone copies update with **Check for Updates…**.
